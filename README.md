# NLP and Sequence Modeling Mini Project

## Project Overview
This project performs sentiment analysis on customer support messages using NLP techniques and sequence modeling concepts.

## Dataset
Dataset: `customer_support_text_classification.csv`

Target column:
- `sentiment_label`
- Positive
- Neutral
- Negative

## Tasks Completed
- Dataset understanding
- Text preprocessing
- TF-IDF vectorization
- Baseline model creation
- LSTM sequence model explanation
- Attention and transformer reflection

## Libraries Used
- pandas
- numpy
- scikit-learn
- tensorflow
- nltk
- matplotlib

## Conclusion
This project helped in understanding NLP preprocessing, sentiment classification, and sequence modeling techniques.
